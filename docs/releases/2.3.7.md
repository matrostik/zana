# What's new in 2.3.7

**Dictate fully offline with local Whisper transcription.** Voice input gains an
experimental local engine: the connected host transcribes with whisper.cpp, so
no audio leaves the machine after the one-time model download.

## New

- **Offline voice dictation (experimental).** Settings → Experimental → Voice
  input offers a Local (whisper.cpp) engine alongside Cloud. Install
  `whisper-cli` on the host (or set its path), download a model in the
  built-in manager (tiny, base, small, medium with progress, cancel and
  delete), and dictate with no network and no per-minute cost. The mic stays
  disabled with the reason until the binary and model are ready, and local
  failures never silently fall back to the cloud.
- **Language hint for OpenAI transcription.** The configured ISO-639 language
  is now sent to the OpenAI API-key path (the Codex backend keeps
  auto-detect).
